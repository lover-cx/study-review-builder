# 复习资料整合生成器（study-review-builder）

> 把课件 / PPT / PDF / Word / 真题等多源资料，一次性整理成**成套可打印、可交互、可自测**的复习资料与预测卷。
>
> 当前版本 **v3.7.0** ｜ Skill 评审 **96.0 / 100（S 级）** ｜ 11 个脚本 ｜ 回归用例 15 项

---

## 一、项目简介

复习资料整合生成器是一个运行在 TeleAgent 平台的 Skill：用户提供多份零散课程资料，AI 按标准工作流完成**知识点划分 → 真题数据驱动星级 → 原卷画像适配 → 出卷 → 校验 → 多格式生成**，一条流水线产出六类交付物。

适用于：学生期末复习、考研（任意满分/题型配比）、四六级等语言类学科、企业内训与培训考核、知识竞赛题库备考等场景。

## 二、核心能力

| 能力 | 说明 |
|---|---|
| **六大交付物** | ①Word 复习册（可点击目录+星级筛选）②四视图交互 HTML（复习/图谱/自测/在线作答判分）③思维导图 PNG ④A/B 两套预测试卷 ⑤参考答案与解析（逐题难度标注）⑥PDF（可选导出） |
| **真题数据驱动星级** ⭐ | 真题命中统计 → 数据星级公式（blend/data/max 多模式），5 星上限约束保证区分度 |
| **原卷画像适配** | 从原卷提取题型/题量/分值/难度画像，预测卷逐套校验与原卷一致，禁止套用 100 分模板 |
| **8+1 种题型** | 选择/判断/填空/简答/材料阅读/听力/翻译/写作 + 多选题（v3.6 起 HTML 在线多选判分） |
| **六层确定性自检** | JSON 校验与三类自动修复 → 题目结构自检 → 答案草稿痕迹扫描 → 个人敏感信息检测（WARN+脱敏预览）→ 试卷总分/题型/难度分布校验 → docx 保存后完整性自检 |
| **大 JSON 分片构建** | 60+ 知识点规模时分片编写，官方 `merge_fragments.py` 合并（含跨片 id 重复检查、`--check` 连动全量校验） |
| **输入提取健壮性** | PPTX/PDF/DOCX/TXT/MD 统一提取；跳过清单 + 「成功提取 N/M」核对；旧式 .doc 可 `--convert-doc` 自动转换；扫描版 PDF 输出页数/图片统计辅助 OCR 决策 |

## 三、快速开始

```bash
# 1. 依赖检查与健康自检（一次即可）
python scripts/setup_deps.py --with-extract
python scripts/setup_deps.py --doctor

# 2. 30 秒验证流水线（官方端到端示例）
python scripts/check_review.py --json references/examples/mini_review.json --strict
python scripts/build_review_docx.py --json references/examples/mini_review.json --out .temp/demo.docx

# 3. 业务示例（培训考核场景）
python scripts/check_review.py --json references/examples/training_review.json --strict
```

正常用户无需手工执行——对 AI 说「帮我把这些课件和真题整理成复习资料，标重点，再出两套预测试卷」并附上文件即可。

## 七、安装与升级

1. 在 TeleAgent 桌面端导入 `study-review-builder-v3.7.0.skill`（zip 格式）；
2. 首次使用前运行 `python scripts/setup_deps.py --with-extract` 安装依赖（python-docx、matplotlib 必需；python-pptx、pymupdf 用于输入提取）；
3. **升级须知**：同名 Skill 在平台不可共存——升级新版前先卸载旧版（设置 → 技能 → study-review-builder → 卸载），再安装新版，否则触发词路由无法区分。

## 八、已知限制与边界

- 扫描版 PDF 无文字层，脚本输出页数/图片统计后需 OCR 或视觉模型识别，不自动替代；
- 旧式 `.ppt` 不支持直接提取（提示先转 `.pptx`）；旧式 `.doc` 需加 `--convert-doc`（仅 Windows，走 Word COM）；
- AI 生成的计算类答案存在出错可能，交付前必须按 SKILL.md 5.4 节逐题验算；
- 检测到的个人敏感信息（考生姓名/学号/手机号等）仅 WARN 提示并脱敏预览，是否脱敏由人工确认，脚本不擅自改动原文；
- 数据与隐私边界：全部本地处理；联网搜索仅发送检索关键词；API 出题仅在用户显式配置 Key 时启用。
